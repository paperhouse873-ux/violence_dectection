# Research Documents

This folder stores research-facing documents and evidence.

- `related_work.pdf`: drafted related work / literature review content.
- `literature_review_matrix.md`: structured notes for at least 5 papers.
- `research_questions.md`: approved RQs, metrics, and evidence mapping.
- `papers/`: raw paper PDFs or per-paper notes.

Keep dataset files out of this folder; dataset protocol belongs in `docs/datasets/`.
